# TEMUKAN - Sistem Barang Hilang

## Deskripsi
TEMUKAN adalah aplikasi web untuk melaporkan barang hilang dan menemukan barang yang ditemukan di lingkungan sekolah. Aplikasi ini memudahkan siswa, guru, dan staf sekolah dalam berbagi informasi barang hilang maupun ditemukan.

**Masalah yang diselesaikan:** Sulitnya melacak barang hilang di sekolah karena informasi tercecer.
**Target pengguna:** Siswa, Guru, dan Staf Sekolah.

## Teknologi yang Digunakan
- **Bahasa:** HTML, CSS, JavaScript
- **Penyimpanan:** localStorage (Browser)
- **Platform Publikasi:** Vercel

## Fitur
1. Lapor barang hilang atau ditemukan
2. Cari barang dengan kata kunci
3. Lihat status laporan (Proses / Ditemukan)
4. Upload foto barang
5. Responsif (bisa diakses HP/PC)
